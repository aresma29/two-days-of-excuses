# Two Days of Excuses

A single-line excuse for the make.fun micro-competition "Two Days of Excuses": complete confidence, completely the wrong week.

## How it works

Run `python3 main.py` from anywhere. The script resolves `entry.txt` relative to its own location (via `pathlib.Path(__file__)`), reads the one-line excuse, strips the trailing newline, and prints it to stdout.
